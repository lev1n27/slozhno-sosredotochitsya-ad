# Сложно сосредоточиться

Проектная работа Яндекс Практикума: адаптивный лонгрид о том, почему сложно сконцентрироваться, в светлой и тёмной темах.

Ссылка на репозиторий: https://github.com/lev1n27/slozhno-sosredotochitsya-ad

## Что сделано

- Адаптивная вёрстка по подходу Mobile first: экраны от 375px, медиазапросы для 768px и 1024px.
- Светлая и тёмная темы на CSS-переменных. Тема выбирается автоматически по `prefers-color-scheme` или принудительно кнопками «День», «Авто» и «Неон».
- Раскладка шапки, секций и галереи на гридах.
- Шапка и подвал высотой в экран, декоративные уголки на псевдоэлементах, размер заголовка через `clamp()`.
- Фиксированный фон страницы, ленивая загрузка изображений галереи, фавиконки для разных устройств.

## Как открыть

Откройте `index.html` в браузере.
